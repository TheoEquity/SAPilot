## 实际摄取检查

此前 5 份保留原集合，只读回查；Max 和旧 DOC 在独立临时集合实际上传检查。以下为检查时状态，临时集合随后已删除：

| 文件 | 文档状态 | 向量/全文索引 | 预览分块 |
| --- | --- | --- | --- |
| FAQ DOCX | COMPLETE | ACTIVE / ACTIVE | 19 |
| Min PDF | COMPLETE | ACTIVE / ACTIVE | 20 |
| 性能 XLSX | COMPLETE | ACTIVE / ACTIVE | 4 |
| ABAP DOCX | COMPLETE | ACTIVE / ACTIVE | 4 |
| 自测规范 DOCX | COMPLETE | ACTIVE / ACTIVE | 18 |
| Max PDF（临时） | COMPLETE | ACTIVE / ACTIVE | 49 |
| 旧 DOC（临时） | **FAILED** | FAILED / FAILED | 0 |

因此仅能说 **6 份解析和索引状态成功、1 份失败**，不能说 7 份摄取验收通过。内容质量另有以下发现：

1. **旧 DOC 缺运行依赖。** 上传 HTTP 200 后，worker 实际报 `soffice command not found`、`No parser can handle file with extension ".doc"`，重试后 FAILED。容器中 `shutil.which('soffice')` 为 False，源码的 DOC 分支要求先转换。本地 Word 可读及 DOCX 可摄取不能代替原 DOC 摄取通过。本轮只记录，未安装依赖或修改解析代码。
2. **FAQ DOCX 保留步骤及图片，部分表外标题未保留。** 19 个 FAQ 均有独立分块；41 次图片引用对应 39 个图片资源，39 个下载均为 200 且 SHA 与原媒体一致。逐 FAQ 比较，图引用顺序及原表归属均匹配。原始连续字符串筛查的 14 个未匹配段落中，两处“步骤一”被行内图片链接打断，去掉图片标记后文字完整，不属于漏步骤；其余 12 个为未逐字保留的表外标题，部分有表内短标题替代。不能将这一差异直接算作业务事实丢失，仍需验证标题中的集团内外等分流上下文是否足够。图片保存正确仍不证明 OCR、图片检索或模型看图通过。
3. **PDF 图片证据未进入当前预览。** Max/Min 原件分别有 166/34 个图片放置位置；当前预览及分块没有 `asset://` 图片引用，视觉索引未启用。Max 新题的 40 条文字引文均在预览保留，但依赖截图的字段、按钮和图文矛盾不能据此称为已摄取。本轮未完成全部 PDF 页逐字及逐截图运行比对。
4. **ABAP 和规范文字筛查未发现长段落丢失。** 对至少 8 个非空白字符的原段落，去排版空白及 Markdown 转义后，ABAP 120 段、规范 78 段均能在预览及合并分块找到。此检查不覆盖更短段落、排版和语义正确性。
5. **XLSX 业务行保留，存在解析噪声。** 主表 19 条原因/方案均保留，包括循环层数、表容量及业务评估条件；标题被当成表头并出现 `Unnamed`、空行 `NaN`，隐藏 WPS 内部表也进入预览。原文末句存在歧义，答案需指出未知，不能擅自替资料修正。

8 条代表性搜索请求全部 HTTP 200，抽查词/编号在返回结果中出现。它们仅检查检索路径可用和证据可取得性，未按 26 题必要证据逐项评分，**不构成 Recall、MRR 或回答通过率**。未运行整套模型答案，也未给速度达标结论。

临时两文档及集合删除均返回 200，随后集合 GET 返回 404；保留私有检查结果。未改动原 5 份文档的集合、Bot 或默认模型。后续正式测试 Max 题时需重新摄取原件并明确图文链路，不能继续使用已删除的临时 ID。

| 题组 | 数量 | 主要难点 |

| 性能排查表 | 4 | 相近现象不同方案、原因/方案行绑定、边界与业务前提、原文歧义 |

26 题中 24 道为业务问答，2 道为材料审计（`FAQ-HARD-06`、`LEGACY-HARD-03`），分别报告，避免把文件格式和内容覆盖审计混入普通业务问答通过率。原来的简单测试保留，不被本难题集覆盖或删除。

统一判分方式：

- 每个必要答案要点逐项 0/1 分；全部必要要点正确、必要证据覆盖、有支撑引用、没有指定硬错误，才算该题通过。部分分用于定位遗漏，不替代通过率。
- 检索按每题语义证据组计算 @1/@3/@5 的覆盖，允许多分块联合和已核验等价来源；MRR 与全证据覆盖分别记录。关键词命中、目录、错误归属图片均不能算完整证据。
- 重复格式只算同一事实；Max 已验证正文可以作为原 FAQ 的替代证据，但不能拿 Max 代替关于 Min 覆盖范围的审计。
- 因格式失败、缺图或环境不可用的题标记 blocked 并保留原因；未运行标记 not_run。业务主口径分母保留 24 道计划题，另外报告已执行子集，不能删除失败或受限题提高成绩。
- 缺少实际日期、配置、审批或根因证据时，正确答案需说明未知和所需材料；示例值不能变成当前工单操作值。

题集包含 **269 条证据记录**（含不同题对同一原文的重复引用）。主代理交叉验证 245 条文字引文记录及 XLSX 61 个单元格，另检查 16 组精确重复页映射、DOC/DOCX 正文/媒体及 FAQ 图片绑定。图中文字单独标为视觉证据，不伪装为正文逐字引用。两子代理的材料及主代理实际检查文件均保留，结论不以代理意见一致代替证据。
