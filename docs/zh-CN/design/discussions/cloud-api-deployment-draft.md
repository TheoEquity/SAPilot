## 2 建议的起步配置

除 CPU 与内存外，下列内容均为建议，具体采购项待确认。

| 项目 | 起步建议 | 说明 |
| --- | --- | --- |
| CPU | 4 核 | 按已确认基线选型 |
| 内存 | 16GB | 按已确认基线选型 |
| 磁盘 | 约 180～200GB SSD | 保存程序、文档、解析产物和索引；最终容量需结合资料量确认 |
| 公网带宽 | 约 10～12Mbps 作为选型参考 | 峰值带宽与固定带宽不可直接等同，需测试实际访问表现 |
| GPU | 暂不购买 | 生成模型走 API；Embedding、重排和解析的运行方式仍需确定 |
| 系统 | Ubuntu 24.04 LTS，x86_64 | 作为部署候选，镜像和依赖兼容性待验证 |
| 部署方式 | 单台云机，Docker Compose | 沿用项目现有服务组成，资源参数需按云机调整 |
| Embedding | 优先考虑 API | 尚未选定供应商或模型；重排、OCR 和文档解析另行确认 |

当前仓库的 [Compose 配置](../../../../docker-compose.yml)包含前后端、Celery、PostgreSQL、Redis、Qdrant 和 Elasticsearch。生成模型走 API 后，应用、摄取和检索服务仍消耗本机 CPU、内存与磁盘，因此 4核16GB 是试运行基线，不是高峰并发容量保证。

## 4 模型 API 选型与费用估算

先采用 `qwen3.8-flash` 配合 SAPilot 的知识库检索，作为成本与效果折中的起步选型。业务知识通过检索材料提供，暂不启动本地生成模型微调。FAQ、SAP 知识问答、ABAP 阅读和运维制度检索是否达到要求，仍需使用项目现有测试集验证；千问 3.7 Plus 可作为效果对照候选，尚未决定启用或建设自动切换。

### 4.1 官方单价

2026 年 10 月 29 日核对的[阿里云百炼官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)如下，按华北2（北京）地域、人民币计价：

| 模型 | 单次请求输入范围 | 输入单价 | 输出单价 |
| --- | --- | --- | --- |
| `qwen3.8-flash` | 0 < Token ≤ 1M | 0.8 元／百万 Token | 2.7 元／百万 Token |

输入包含系统提示词、用户问题、检索材料、聊天历史及工具返回内容；输出预算应包含计费的思考 Token 和最终回答。下列估算不抵扣免费额度，不计缓存或批量调用折扣，实际费用以账单和届时单价为准。

### 4.2 团队月费估算

以下为测算假设，不是实测用量或用户已确认的使用频率：50 人，每人每天提问 10 次，每月使用 22 天；每问调用一次生成模型，每次输入合计 10,000 Token、计费输出合计 1,000 Token。

| 项目 | 计算方式 | 估算结果 |
| --- | --- | --- |
| 每月问答数 | 50 × 10 × 22 | 11,000 次 |
| 每月输入费用 | 11,000 × 10,000 ÷ 1,000,000 × 0.8 | 88.00 元 |
| 每月输出费用 | 11,000 × 1,000 ÷ 1,000,000 × 2.7 | 29.70 元 |
| 每月生成模型费用 | 88.00 + 29.70 | **117.70 元，约 118 元／月** |
| 年度生成模型费用 | 117.70 × 12，假设每月用量相同 | **1412.40 元，约 1412 元／年** |

该费用仅覆盖上述一次生成调用。若改写、路由、工具循环等额外调用生成模型，需累加对应 Token；更长的聊天历史、检索材料或思考输出也会提高费用。Embedding、重排、OCR、文档解析、云服务器、额外磁盘及备份均未计入本节估算，尚不能将其作为完整年度总预算。

上线前核实目标账号的[模型限额](https://help.aliyun.com/zh/model-studio/quota-management)，并验证高峰 20 人提问时的实际表现；官方配额不能替代应用端到端压测。
