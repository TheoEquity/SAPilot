# SAPilot 小周期总结报告

日期：2026 年 10 月 31 日（America/New_York）。用户确认本小周期结束。本报告汇总本周期已有实现、实际验证和保留事项；本次只整理记录，没有重新运行整套评测或进行新的功能开发。

本周期已形成一套可以继续开发和本地测试的知识库主流程：原始七份材料能够摄取，文字与图片可以进入问答，来源、历史和关键日志有据可查，已有难题集能够复跑和逐题判分。按本期调整后的目标，以基本流程和工程收尾结项；百份文档扩展、八成质量指标、容量及生产部署验收留待后续安排。

| --- | --- | --- |

本周期建立的维护方式已经可以用于后续需求。HTTP 接口以 FastAPI 路由和 Python 请求、响应模型为维护源，OpenAPI 由脚本导出，Swagger/ReDoc 用于查看，Orval 生成前端类型、调用和基础 Mock；可按业务分组导出多份。新增接口优先新增对应实现文件，修改接口改对应实现，不再手工同步维护三套接口定义。旧 SDK 按实际需求逐模块迁移。Mock 开发后停止临时服务、清空运行数据，再按真实接口联调；保留必要测试夹具。

日志沿用轻量实现：前端使用项目统一 `logger`，后端及 worker 使用 Python `logging`，模型和工具观测进入 Langfuse；配置集中在 `config/logging/`，默认文件输出在项目旁 `../SAPilot-data/logs/`。浏览器日志仍在控制台，按需导出，没有另建浏览器日志采集平台或额外堆叠关联 ID。

| 材料审计题 | 0 / 2 | 0% |

题目覆盖跨段落、跨页、条件分支、相似问题辨别、重复与节选范围审计，以及以图找图、局部截图、图中文字、图组关系和证据不足澄清。完整文字答复 P50/P95 为 54.73/86.89 秒，图片答复中位约 82.97 秒、最大约 99.11 秒。这是本批运行耗时，速度和并发没有完成正式验收。正式语义 Recall/MRR 未完成；纯图片向量检索在五道唯一原图题上的 Hit@1/@3 为 1/5，混合检索补到正确来源不能替代纯图片向量效果。

用户试用期间发现的两个页面问题也已单独处理：正文成功后，可选自动标题接口 400 导致未处理异常；以及已处理的聊天失败仍触发开发错误层、等待不结束。前者现保留回答并记录警告，后者现保留聊天内错误提示并恢复输入。最后一次用户贴出的 Console Error 对应更早的普通账号失败会话，当前管理员回答有成功完成日志，刷新后仍保留。管理员后台标题模型仍未配置，该直接接口的 400 没有被写成已经消失。

普通账号 `sapilot_tester` 已按用户要求接入同七份材料的独立私有测试能力，默认测试助手为“七份材料测试助手”。七份原件及三类索引完成后已有最终回读；文字样例约 28.0 秒、图片样例约 60.70 秒，均正常结束并有来源，图片下载核验通过。三个补验会话在 Langfuse 对应 7 次模型调用。管理员来源配置保留，账号没有提权，浏览器保留管理员登录；其他新账号不会自动继承这套测试配置。

本周期发生过一次本地测试认证材料误输出。随后按用户授权撤销旧测试 Key、更换本地 JWT 签名密钥，并实际验证旧 Key/Cookie 及旧 WebSocket 认证失效，新登录、问答、前端代理和监控可用。历史工具输出的传播及保留范围仍未核实。本报告不包含密码、Key 或 Cookie。各轮自身创建的临时会话、查询图及辅助 worker 按记录清理，原材料、工作知识库、用户原会话和历史评测证据保留。

保留事项已明确，不自动开启新一轮工作：

- **回答质量**：细字 OCR、图组与条件漏答、部分跨页归属、材料版本与范围审计、图片候选排序仍有失败题。
- **追问与旧分支**：追问路由按用户决定暂缓；旧 Flow 的限制、OpenAI 兼容接口未实现及需额外凭据/数据的接口沿用原记录，不声称全接口通过。
- **工程与使用边界**：已有 57 条前端 lint warning、后端 28 个文件的格式差异未批量整改；最终完整页面验收未补齐，普通账号配置检查是代表性功能补验。
- **规模与部署**：暂不扩展至约 100 份文档，不追八成指标；容量、多人并发、生产部署及生产日志出口未验收。

后续若开启新周期，建议从具体使用需求或一个明确遗留问题开始，约定行为和验收后复用现有题集与回归，不重做高层架构。本报告不构成对这些后续工作的实施批准。
