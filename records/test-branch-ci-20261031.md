| 检查 | 依据与范围 |
| --- | --- |

初始版本本地完成 **180 项契约测试**、前端相关 **24 项**及静态检查；这属于调整前的验证记录，不代表这些回归仍在 CI 运行。基础 UI 的违规导入探针被明确报错，正常纯 UI 探针通过，没有将探针文件加入仓库。前端 lint 原有 warning 保持警告，不设置零 warning 门槛；Python `config/` 的既有 18 项告警未纳入这次硬门槛，后续可另行处理，未通过忽略新增错误的方式宣称全仓干净。

这套 CI 不等于全部规约已自动执行。职责是否合理、是否过度设计、权限和事务设计、私有凭据处理以及真实页面/模型/摄取效果仍需对应审查或运行验证。没有设置分支保护或 required checks；CI 红灯会显示失败，但本次没有更改 GitHub 的强制合并规则。
