# 开发需求启动 Prompt

这是需求已经明确、准备交给 Agent 开发时手动取用的模板。需要时可以说“把开发需求的 Prompt 拿出来”，查看后复制填写；它不是日常开发的必读文件，也不会自动启动任务。

项目规则见 [AGENTS.md](../AGENTS.md)，开发与验证方式见[开发流程](../specs/development-workflow.md)。本文件只保存启动模板，不另维护一套规约。

## 可复制模板

```text
这个需求已经明确，请按本项目 AGENTS.md 及其引用的相关规约实施。

目标：［用户要解决的问题和预期行为］
范围：［本次涉及的功能和关键边界］
验收：［哪些可观察结果代表完成］
已确认的约束或决定（如有）：［补充内容］

请按以下方式推进：
1. 先核对直接相关的源码、配置、调用方和现有测试，优先复用已有能力；用几句话说明必要改动、实现方式和验证范围，不为这个需求重做全项目架构调查。
2. 沿用已经明确的需求、决定和授权。信息足够时继续实施；只有缺失信息会改变结果、范围或验收含义时才提问，不重复确认已有结论。公共变更按项目现有规约处理。
3. 只完成本次目标所必需的工作，采用最小充分改动，不顺手增加功能、抽象或全仓重构。保留工作区中其他未提交改动。
4. 对照验收要求检查正常路径、必要异常和直接受影响的旧行为。发现具体问题后定位、修复，再运行相关检查；没有新问题时不反复扩大测试范围。
5. 完成后说明改了什么、依据是什么、实际验证了什么，以及未验证项或剩余问题。未执行的检查如实说明，不将代码写完或生成成功等同于业务验收通过。
```
