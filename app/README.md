# SAPilot application

This directory contains the Python API and workers (`aperag/`, `config/`), the Next.js frontend (`web/`), tests, dependency manifests and application build/deployment files.

Run application development commands from this directory. Project navigation is in the [root README](../README.md); development requirements are in [docs/specs](../docs/specs/). Local credentials are in `.env`, while service logs and task artifacts belong in `../runtime/`.
